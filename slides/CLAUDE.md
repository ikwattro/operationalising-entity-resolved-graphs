# Marp Slides

Single-presentation repo built with [Marp](https://marp.app/).

## Workflow

Edit `slides.md` directly. **Do not run build commands** — just edit the source file.

```bash
make build    # HTML → dist/slides.html
make pptx     # PPTX → dist/slides.pptx
make pdf      # PDF  → dist/slides.pdf
```

Run `/slides` for full slide authoring rules and template reference.
